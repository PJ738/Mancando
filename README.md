# The Man Can Do (เฟส 1)

แอปส่วนตัวสำหรับดูโปรแกรมเวท เมนูอาหาร และบันทึกน้ำหนัก ทำงานบน iPhone แบบเว็บแอป (PWA)
ไม่ต้องใช้ Mac ไม่ต้องมีบัญชี Apple Developer และไม่มีค่าใช้จ่าย

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `data.js` | โปรแกรมเวท เมนูอาหาร คำแนะนำ (แก้ท่า/เมนูที่นี่) |
| `app.js` | ตรรกะและหน้าจอของแอป |
| `style.css` | หน้าตา (รองรับโหมดมืดอัตโนมัติ) |
| `index.html`, `manifest.webmanifest`, `sw.js`, `*.png` | ส่วนที่ทำให้ติดตั้งบนหน้าจอโฮมและเปิดออฟไลน์ได้ |

## ทดลองบนคอมก่อน (ไม่บังคับ)

เปิดโฟลเดอร์ใน VS Code แล้วใช้ส่วนเสริม Live Server หรือรันในเทอร์มินัล

    python3 -m http.server 8000

จากนั้นเปิด http://localhost:8000

## ติดตั้งบน iPhone

1. สร้าง repository บน GitHub (ฟรี) เช่นชื่อ `mancando`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ปุ่ม Add file > Upload files) หรือ push ผ่าน VS Code
3. ไปที่ Settings > Pages > Source: Deploy from a branch > เลือก `main` และโฟลเดอร์ `/ (root)` > Save
4. รอ 1-2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/mancando/`
5. เปิดลิงก์ใน **Safari** บน iPhone > ปุ่มแชร์ > **เพิ่มไปยังหน้าจอโฮม**
6. ใช้งานจากไอคอนบนหน้าจอโฮมทุกครั้ง

### ข้อควรรู้

- **ติดตั้งก่อนแล้วค่อยเริ่มจดข้อมูล** บน iOS ข้อมูลของ Safari กับไอคอนบนหน้าจอโฮมแยกกัน ถ้าจดใน Safari ก่อนติดตั้ง ข้อมูลจะไม่ตามมา
- repository แบบ public จะมองเห็นโค้ดและเมนูในแผนได้ แต่ **ข้อมูลน้ำหนักและบันทึกเก็บในเครื่องคุณ ไม่ได้ขึ้นเซิร์ฟเวอร์**
- **ลบไอคอนออกจากหน้าจอโฮม หรือล้างข้อมูลเว็บไซต์ = ข้อมูลหาย** ให้กด "คัดลอกข้อมูล" ในแท็บ "ข้อมูล" แล้วเก็บไว้ในโน้ตหรืออีเมลทุกสัปดาห์
- ใช้งานออฟไลน์ได้หลังเปิดแอปครั้งแรกตอนมีอินเทอร์เน็ต

## อัปเดตแอป

แก้ไฟล์ (เช่น `data.js`) แล้ว push ขึ้น GitHub จากนั้นเปิดแอปตอนมีอินเทอร์เน็ต ปิดแล้วเปิดใหม่อีกครั้ง จะได้เวอร์ชันล่าสุด
ข้อมูลที่จดไว้ไม่หาย
